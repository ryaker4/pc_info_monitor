PC Info Monitor

## Установка 

Зависимости
```
pip install -r requirements.txt
```
Запуск виртуального окружения:
```
source .venv/bin/activate
```
Выключение:
```
deactivate
```
## Программы

### hardware.ry 
Получение сведений об комплектующих
Название параметра	Описание параметра
-h, --help	Вывод короткой справки по параметрам
-v, --verbose	Подробный вывод(пока ничего не делает)
-o, --output	 Сохранение в файл, нужно передать название файла
cpu	Вывод сведений о процессоре
memory	Вывод сведений об оперативной памяти
disk 	Вывод сведений о дисках
all	Вывод сразу cpu, memory, disk

Запуск
```
python3 src/hardware.py all
```
Вместо all можно выводить по отдельности cpu, memory, disk.
### gui_hardware.py
Графическое представление сведений, не в терминале.
```
python3 src/gui_hardware.py
```
### log_hardware.py
Сбор сведений об процессоре и оперативной памяти в заданный файл
Появились дополнительные параметры 
Название параметра	Описание параметра
-t, --time	Задает интервал для получения логов. Указывается в секундах. По умолчанию 5 секунд.
--log	Включает режим логгирования. Файл по умолчанию system_log.csv
Запуск(минимальный)
```
python3 src/log_hardware.py all —log
```
### static_graph.py
Читает логи, собранные программой log_hardware.py или monitor_hardware.py и строит статичный график использования CPU и RAM.
Запуск:
```
python3 src/static_graph.py
```
Дальше нужно будет ввести название файла с логами.
### monitor_hardware.py
Собирает сведения об использовании процессора, оперативной памяти, дискового пространства и сети. Записывает в файл.
Запуск:
```
python3 src/monitor_hardware.py all --log -o sys_log_1.csv -t 5
```
Можно не передавать параметр -o, тогда логи запишутся в файл system_log.csv
### dynamic_graph.py
Читает логи в реальном времени и строит динамические графики использования процессора, оперативной памяти, дискового пространства и сети.
Запуск:
```
python3 src/dynamic_graph.py
```
После ввода потребуется ввести название файла с логами.
Для динамических графиков нужно использовать в связке с monitor_hardware.py
